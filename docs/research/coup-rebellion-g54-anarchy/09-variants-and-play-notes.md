# 09 Variants and Play Notes

## Difficulty

Every Anarchy role is advanced. The rulebook marks no role as basic. Web version should tag all six Anarchy roles and Social Media as advanced in the UI. Keep the base G54 starter set for first games and add Anarchy roles only for experienced tables.

## Integration With Base G54

Anarchy role action cards join the base category piles. The base draft rule is unchanged. A game may include zero, one, or several Anarchy roles. Anarchy does not require a fixed set.

When both base and Anarchy roles are in the pool, the base self block rule still holds. Paramilitary is blocked by Paramilitary. There is no cross block between base and Anarchy roles.

## Social Media Interaction With Communications Roles

Social Media lets any player swap a card with the deck every turn. This reduces the value of some Communications roles because a swap is available to everyone. Community review notes that base Communications roles lose some of their purpose when Social Media is in play. This is a design consequence, not a bug.

## Recommended Sets With Anarchy

Force plus Finance game is Financier, Director, Anarchist, Arms Dealer, Socialist. Tests the Bank pile and the bomb chain.
Money game is Plantation Owner, Reporter, Paramilitary, Arms Dealer, Socialist. Tests mass payout and card redistribution.
Mixed game is Banker, Producer, Anarchist, Financier, Arms Dealer. Tests a base income role against the Bank swap.
Treat these as product suggestions, not official canon.

## Balance Notes From Community

Anarchy is an addition, not an overhaul. Base G54 plays fine without it. Force and Finance gain more options, which was a gap in base G54. Communications gains none, and Social Media replaces that slot.

Plantation Owner encourages mass claiming, which can hand opponents more coins than the claimant wants. Financier makes everyone watch the Bank pile, so players avoid Income and steal instead. Anarchist is interesting because the claim needs no held card, but a defuse or pass can waste the 3 coin cost. Paramilitary is a Guerrilla with a sliding cost, cheaper against a full health target and pricier against a nearly dead one. Arms Dealer is a luck swing for 4 coins. Socialist is the community favorite because it disrupts hands and plans.

## Open Questions

Whether the active player learns which Socialist giver sent which card needs a card text check. Primary reading is the cards are collected hidden and shuffled.
Whether a Socialist target may give a card they do not want to reveal, and how the keep step handles it, needs a card text check.
Whether Arms Dealer payout doubles if both revealed cards match the named role needs a card text check. Primary reading is 4 coins flat.
Whether the Bomb chain continues if a pass target is the last eligible holder needs a ruling. Primary reading is the target must defuse or take the loss.
Whether Plantation Owner payout counts the active player as a claimant needs a card text check. Primary reading is yes, the active player's own claim counts.
Whether Bank replaces Income for challenge or block purposes only, or removes the Income action entirely, needs a card text check. Primary reading is Income is removed while Financier is in play.
